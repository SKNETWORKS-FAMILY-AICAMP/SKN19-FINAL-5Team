## 🚀 3단계: 검색 API 실행 (1분)

> ✅ **DB 준비 완료**: AWS RDS는 이미 최신 상태로 업데이트되었습니다. 바로 API를 실행하면 됩니다!

### 💡 중요: 두 파일의 차이

프로젝트에 두 개의 Python 파일이 있습니다:

| 파일 | 역할 | 실행 형태 |
|------|------|-----------|
| **`03_01_search_api.py`** | **API 서버** (FastAPI) | 계속 실행 (Ctrl+C로 종료) |
| **`03_02_test_search_api.py`** | **테스트 클라이언트** | 일회성 실행 (자동 종료) |

**비유**:
- `03_01_search_api.py` = 레스토랑 (주문을 받고 요리를 제공)
- `03_02_test_search_api.py` = 손님 (주문하고 음식을 평가)

**관계**:
```
터미널 1: python 03_01_search_api.py  ← 서버 실행 (계속 대기)
         ↕ HTTP 요청/응답
터미널 2: python 03_02_test_search_api.py  ← 테스트 실행 (자동 종료)
```

⚠️ **테스트 스크립트는 서버가 실행 중이어야만 작동합니다!**

import requests

response = requests.post(
    "http://localhost:8000/search",
    json={
        "query": "환불 거부 해결 방법",
        "search_type": "hybrid",  # BM25 + 벡터 검색

print(f"총 {len(results['results'])}개 결과")
for r in results['results']:
    print(f"점수: {r['score']:.4f} | {r['text'][:100]}...")

## 🎯 검색 타입별 설명

| 검색 타입 | 설명 | 추천 상황 |
|----------|------|-----------|
| `hybrid` | BM25 + 벡터 검색 + RRF | **대부분의 경우 사용 (가장 정확)** |
| `vector` | 임베딩 기반 의미 유사도 검색 | 유사한 의미의 문장 찾기 |

## 🔧 문제 해결

### ❌ DB 연결 실패

**증상**: `connection refused` 또는 타임아웃

**해결**:
1. `.env` 파일이 프로젝트 루트(`data_n_db/.env`)에 있는지 확인
2. RDS 접속 정보가 정확한지 확인 (팀 채널에서 재확인)
3. 인터넷 연결 확인

### ❌ OPENAI_API_KEY 오류

**증상**: `AuthenticationError: Incorrect API key`

**해결**:
1. `.env` 파일에 `OPENAI_API_KEY` 추가
2. 팀 채널에서 API 키 받기
3. API 서버 재시작

### ❌ 패키지 설치 오류

**증상**: `ModuleNotFoundError`

**해결**:
```bash
# 가상환경 확인
conda activate ddoksori

# requirements.txt 재설치
pip install -r requirements.txt --upgrade
```

### ❌ 포트 충돌

**증상**: `Address already in use`

**해결**:
```bash
# 다른 포트로 실행
uvicorn 03_01_search_api:app --port 8001
```
