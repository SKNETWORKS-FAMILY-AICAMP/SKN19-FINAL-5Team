# 법률/시행령 JSON 구조 분석

---

## 1. 최상위 구조

```json
{
  "법령명": "소비자기본법",
  "시행일": "2026-01-02",
  "법령번호": "법률 제21065호",
  "구조": [...],   // 편/장/절이 있는 법령
  "조문": [...]    // 편/장/절이 없는 법령
}
```

| 키 | 설명 |
|----|-----|
| 법령명 | 법령의 공식 명칭 |
| 시행일 | YYYY-MM-DD 형식 |
| 법령번호 | 법률: `법률 제XXXXX호`, 시행령: `대통령령 제XXXXX호` |
| 구조 | 편/장/절 계층이 있는 법령에서 사용 |
| 조문 | 편/장/절 없이 조문만 있는 법령에서 사용 |

---

## 2. 법령 구조 유형

### 유형 A: 편-장-절 구조 (민법, 상법)

```
구조
└─ 편 (제목: "제1편 총칙")
    └─ 장 (제목: "제1장 통칙")
        └─ 절 (제목: "제1절 능력")
            └─ 조문 [...]
```

```json
{
  "구조": [
    {
      "제목": "제1편 총칙",
      "장": [
        {
          "제목": "제1장 통칙",
          "조문": [...]
        },
        {
          "제목": "제2장 인",
          "절": [
            {
              "제목": "제1절 능력",
              "조문": [...]
            }
          ]
        }
      ]
    }
  ]
}
```

### 유형 B: 장 구조 (소비자기본법, 방문판매법 등 대부분)

```
구조
└─ 장 (제목: "제1장 총칙")
    └─ 조문 [...]
```

```json
{
  "구조": [
    {
      "제목": "제1장 총칙",
      "조문": [...]
    },
    {
      "제목": "제2장 소비자의 권리와 책무",
      "조문": [...]
    }
  ]
}
```

### 유형 C: 단순 조문 구조 (제조물책임법, 약관규제법)

```
조문
└─ 제1조, 제2조, 제3조...
```

```json
{
  "조문": [
    { "조문번호": "제1조", "조문제목": "목적", "내용": [...] },
    { "조문번호": "제2조", "조문제목": "정의", "내용": [...] }
  ]
}
```

## 3. 조문 내부 구조

### 조문 기본 형태

```json
{
  "조문번호": "제2조",
  "조문제목": "정의",
  "내용": [...]
}
```

### 내용 배열의 요소 유형

| 유형 | 키 | 패턴 | 설명 |
|-----|---|-----|-----|
| 본문 | `본문` | 일반 텍스트 | 조문 첫 문장 또는 항 앞 문장 |
| 항 | `항번호`, `내용`, `세부` | ①②③... | 조문 하위 항목 |
| 호 | `호`, `내용`, `세부` | 1. 2. 3. | 항 또는 조 하위 항목 |
| 목 | `목`, `내용` | 가. 나. 다. | 호 하위 항목 |

### 계층 구조 다이어그램

```
조문 (조문번호, 조문제목)
├─ 본문 {"본문": "이 법에서 사용하는 용어의 뜻은..."}
│
├─ [케이스1] 조 → 항 → 호 → 목
│   └─ 항 {"항번호": "①", "내용": "...", "세부": [...]}
│       └─ 호 {"호": "1", "내용": "...", "세부": [...]}
│           └─ 목 {"목": "가", "내용": "..."}
│
└─ [케이스2] 조 → 호 → 목 (항 없이 바로 호)
    └─ 호 {"호": "1", "내용": "\"소비자\"라 함은...", "세부": [...]}
        └─ 목 {"목": "가", "내용": "..."}
```

### 예시: 제2조(정의) - 케이스2 (조 → 호)

```json
{
  "조문번호": "제2조",
  "조문제목": "정의",
  "내용": [
    { "본문": "이 법에서 사용하는 용어의 뜻은 다음과 같다." },
    { "호": "1", "내용": "\"소비자\"라 함은 사업자가 제공하는..." },
    { "호": "2", "내용": "\"사업자\"라 함은 물품을 제조..." },
    {
      "호": "5",
      "내용": "\"다단계판매\"란 다음 각 목의 요건을...",
      "세부": [
        { "목": "가", "내용": "판매업자에 속한 판매원이..." },
        { "목": "나", "내용": "가목에 따른 판매원의 가입이..." }
      ]
    }
  ]
}
```

### 예시: 제3조 - 케이스1 (조 → 항 → 호)

```json
{
  "조문번호": "제3조",
  "조문제목": "제조물 책임",
  "내용": [
    { "본문": "① 제조업자는 제조물의 결함으로..." },
    {
      "항번호": "②",
      "내용": "제1항에도 불구하고 제조업자가...",
      "세부": [
        { "호": "1", "내용": "고의성의 정도" },
        { "호": "2", "내용": "해당 제조물의 결함으로 인하여..." }
      ]
    }
  ]
}
```

## 4. 법률 vs 시행령 비교

| 구분 | 법률 (11개) | 시행령 (8개) |
|-----|-----------|------------|
| 법령번호 형식 | `법률 제XXXXX호` | `대통령령 제XXXXX호` |
| 내용 성격 | 기본 원칙, 권리/의무 규정 | 법률 위임 사항, 세부 시행 규정 |
| 구조 형태 | 동일 (편/장/절 또는 장 또는 단순) | 동일 |
| 조문 계층 | 동일 (조→항→호→목) | 동일 |
