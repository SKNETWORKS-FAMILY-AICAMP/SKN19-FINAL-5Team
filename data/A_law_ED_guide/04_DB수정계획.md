# DB 수정 계획 - 법률 메타데이터 구조화 프로젝트

## 📋 문제 분석

### 현재 상황
- **law_guide 데이터의 메타데이터가 비어있음**
  - `keywords`: 빈 배열
  - `위임대상`: 빈 배열 (상위 법률 → 하위 시행령 위임 정보)
  - `준용조문`: 빈 배열 (다른 조문을 준용하는 관계)
  - `참조조문`: 빈 배열 (관련 조문 참조)

### 근본 원인
- **파싱 단계에서 메타데이터를 추출하지 않음**
  - 조문 관계 정보가 본문에만 존재: "제42조제2항의 규정은 전2항의 경우에 준용한다"
  - 구조화된 형태로 추출되지 않아 관계 검색 불가능

### 영향
- ❌ 법률 간 관계 추적 불가 (예: 소비자기본법 → 소비자기본법 시행령)
- ❌ 조문 간 준용 관계 탐색 불가
- ❌ 관련 조문 자동 검색 불가
- ❌ RAG 시스템의 법률 해석 정확도 저하

---

## 🎯 해결 방안: LLM 기반 재파싱 (Option 2)

### 선택 이유
1. **정확도**: 정규식보다 복잡한 법률 문맥 이해 가능
2. **유연성**: 다양한 표현 방식 대응 가능
3. **비용 효율**: API 방식보다 저렴 (1회 파싱으로 완료)
4. **확장성**: 향후 다른 메타데이터 추가 용이

```python
from openai import OpenAI
import json

def extract_metadata_with_llm(article_number, article_title, content, law_name):
    """
    LLM을 사용하여 조문에서 구조화된 메타데이터 추출
    """
    client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

    prompt = f"""
다음 법률 조문을 분석하여 JSON 형태로 메타데이터를 추출해주세요.

**법률명**: {law_name}
**조문번호**: {article_number}
**조문제목**: {article_title}
**조문내용**:
{content}

다음 정보를 추출하세요:
1. **위임대상**: 이 조문이 하위 법령(시행령, 시행규칙 등)에 위임하는 내용이 있다면 추출
   - 형식: ["제5조제1항", "제10조"] 같이 조문 번호 리스트
   - 예시: "대통령령으로 정한다", "총리령으로 정한다" 등의 표현 찾기

2. **준용조문**: 이 조문이 다른 조문을 준용한다면 추출
   - 형식: ["제42조제2항", "제50조"] 같이 조문 번호 리스트
   - 예시: "제42조제2항의 규정은...준용한다"

3. **참조조문**: 이 조문에서 참조하는 다른 조문
   - 형식: ["제16조", "제20조제1항"] 같이 조문 번호 리스트

4. **keywords**: 이 조문의 핵심 키워드 (3-5개)
   - 예시: ["소비자", "권리", "안전"]

**출력 형식** (JSON):
{{
  "위임대상": [],
  "준용조문": [],
  "참조조문": [],
  "keywords": []
}}

해당 정보가 없으면 빈 배열로 반환하세요.
"""

    response = client.chat.completions.create(
        model="gpt-4o-mini",  # 비용 절감
        messages=[
            {"role": "system", "content": "당신은 대한민국 법률 전문가입니다. 법률 조문을 분석하여 정확하게 메타데이터를 추출합니다."},
            {"role": "user", "content": prompt}
        ],
        temperature=0.1,
        response_format={"type": "json_object"}
    )

    metadata = json.loads(response.choices[0].message.content)
    return metadata
```

**수정할 파싱 로직**:
```python
# 기존: 메타데이터 없이 파싱
parsed_data = {
    "조문번호": article_number,
    "조문제목": article_title,
    "내용": content
}

# 수정 후: LLM 메타데이터 추가
metadata = extract_metadata_with_llm(article_number, article_title, content, law_name)
parsed_data = {
    "조문번호": article_number,
    "조문제목": article_title,
    "내용": content,
    "위임대상": metadata.get("위임대상", []),
    "준용조문": metadata.get("준용조문", []),
    "참조조문": metadata.get("참조조문", []),
    "keywords": metadata.get("keywords", [])
}
```

```python
"""
law_guide 데이터만 교체하는 스크립트
case 데이터는 그대로 유지
"""
import psycopg2
from psycopg2.extras import execute_values
import json
from pathlib import Path

def replace_law_guide_data():
    # 1. 기존 law_guide 데이터 백업
    conn = psycopg2.connect(**DB_CONFIG)
    cursor = conn.cursor()

    # 백업 테이블 생성
    cursor.execute("""
        CREATE TABLE IF NOT EXISTS vector_chunks_backup_law AS
        SELECT * FROM vector_chunks WHERE dataset = 'law_guide';
    """)
    conn.commit()
    print("✅ 기존 law_guide 데이터 백업 완료")

    # 2. 기존 law_guide 데이터 삭제
    cursor.execute("DELETE FROM vector_chunks WHERE dataset = 'law_guide';")
    conn.commit()
    print("✅ 기존 law_guide 데이터 삭제 완료")

    # 3. 새 데이터 삽입
    embedded_files = Path("A_law_ED_guide/01_A_parsed/03_law_ED_embedded").glob("*.json")

    total_inserted = 0
    for file in embedded_files:
        with open(file, 'r', encoding='utf-8') as f:
            data = json.load(f)

        # 배치 삽입
        values = []
        for item in data:
            values.append((
                item['chunk_id'],
                item['content'],
                item['embedding'],
                json.dumps(item['metadata']),  # 메타데이터 포함
                item['law_name'],
                item['article_number'],
                # ... 기타 컬럼
            ))

        execute_values(cursor, """
            INSERT INTO vector_chunks
            (chunk_id, content, embedding, metadata, law_name, article_number, ...)
            VALUES %s
        """, values)

        total_inserted += len(values)
        print(f"  - {file.name}: {len(values)}개 삽입")

    conn.commit()
    print(f"✅ 총 {total_inserted}개 law_guide 데이터 삽입 완료")

    # 4. 검증
    cursor.execute("""
        SELECT COUNT(*) as total,
               COUNT(*) FILTER (WHERE metadata->>'위임대상' != '[]') as with_delegation,
               COUNT(*) FILTER (WHERE metadata->>'준용조문' != '[]') as with_reference
        FROM vector_chunks WHERE dataset = 'law_guide';
    """)
    result = cursor.fetchone()
    print(f"""
✅ 검증 결과:
   - 총 law_guide 청크: {result[0]}개
   - 위임대상 있음: {result[1]}개
   - 준용조문 있음: {result[2]}개
    """)

    cursor.close()
    conn.close()

if __name__ == "__main__":
    replace_law_guide_data()
```
